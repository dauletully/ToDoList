# To-Do List App📋
A simple To-Do List application built with **Swift** **UIKit**, following the **MVVM (Model-View-ViewModel)** architecture, and using **Core Data** for persistent storage.

---

# Features
- Add, delete and update tasks 🗒️
- Filter tasks by searching title or details 🔍
- Persistent storage using Core Data 🗄️
- A new page for editing notes
- MVVM architecture for clean and maintainable code

## Architecture 🏗️
This project follows the MVVM architecture for better separation of concerns:

- Model: Task entity is managed using Core Data.
- View: TaskListViewController, TaskEditViewController, and custom views for UI.
- ViewModel: TaskViewModel mediates between the View and Model layers.

---

## Technologies Used 🖥️
- Swift 5
- Core Data for local storage
- SnapKit for simplifies Auto Layout in Swift, significantly enhancing iOS development productivity
- UIKit for UI design
- MVVM Architecture
